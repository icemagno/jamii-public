Diferenciais Tecnológicos (The Jamii Edge)

Inovações arquiteturais desenvolvidas para garantir escalabilidade, segurança pós-quântica e I/O de milissegundos.

1. Identidade Unificada Shadowless (Zero Migration UX)

Um único payload de chaves tradicionais (Secp256k1) e quânticas (ML-DSA-65) mapeia para a mesma conta no World State. Serve de forma unificada tanto a endereços clássicos Ethereum (0x...) quanto soberanos (jamii1...), eliminando a necessidade de migração de saldos.

2. Bonsai Turbo (O(1) I/O nativo em Go)

Elimina a descida de árvore tradicional ($O(\log N)$ acessos a disco). O Jamii implementa o Bonsai Turbo sobre o PebbleDB, garantindo acesso a saldos e contas em tempo constante $O(1)$, relegando a escrita de árvore ao segundo plano.

3. Trie Criptográfica Paralela (Multi-core SMT & Verkle)

Seja utilizando SMT ou Verkle Tree (IPA/Bandersnatch), o Jamii paraleliza a computação de hashes de subárvores e compromissos polinomiais complexos usando goroutines e semáforos, aproveitando 100% dos núcleos de CPU.

4. Chained State Oracle (Synchronous Pacing)

Utiliza a cadência física de blocos para garantir consistência. A montagem do bloco ocorre de forma estritamente síncrona e segura no início do turno de liderança, sobre uma base PebbleDB consolidada e livre de escritas concorrentes.

5. Witness-Aided Quorum Acceleration

Separa a prova de estado do quórum de votação. Validadores utilizam o "Witness" para aprovar o bloco instantaneamente em RAM, enquanto a prova IPA pesada é processada em paralelo, eliminando o gargalo tradicional do IBFT.

6. Ultra-Compact Skeleton (Bi-Polar)

Redução de 81% no tráfego de rede. Blocos com 3.000 TXs trafegam usando identificadores de 6 bytes (3 iniciais + 3 finais), permitindo que o dado chegue antes do sinal de consenso.

Começando

Gere sua identidade soberana e execute nós validadores ou de arquivo via Docker.

1. Configuração Inicial (Setup de Identidade Soberana)

Antes de iniciar um nó pela primeira vez, gere a chave privada híbrida PQC e o arquivo de endereço:

Bash / Command Line 
# Gera a identidade no diretório padrão (./data)
jamii.exe setup generate-key

# Ou especificando um diretório customizado
jamii.exe setup generate-key --datadir ./meu_node_data

2. Executando os Containers Docker

docker-run-node.sh 
docker run \
  --name jamii-node \
  -v ./config.yaml:/config.yaml:ro \
  -v ./genesis.json:/genesis.json:ro \
  -v ./peers.json:/peers.json:ro \
  -v ./datadir:/datadir \
  -p 8545:8545 \
  -p 30303:30303 \
  -p 42000:42000 \
  -d magnoabreu/jamii-node:0.1.0-alpha
docker-run-archiver.sh 
docker run \
  --name jamii-archiver \
  -v ./config.yaml:/config.yaml:ro \
  -v ./genesis.json:/genesis.json:ro \
  -v ./peers.json:/peers.json:ro \
  -v ./datadir:/datadir \
  -p 8556:8556 \
  -p 30310:30310 \
  -p 42020:42020 \
  -d magnoabreu/jamii-archiver:0.1.0-alpha
